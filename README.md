# SDS-Proctor-Clock

A clean, distraction-free full-screen clock for proctoring exams.

**[🌐 Open SDS-Proctor-Clock →](https://sanjeev-rm.github.io/SDS-Proctor-Clock/)**

## Features

### 🕐 Clock Display

- Large, easy-to-read time display
- Toggle between 12-hour and 24-hour format
- Show/hide seconds option
- Dark and light theme support

### 📅 Date Display

- Full date with day of the week
- Toggle on/off as needed

### 📝 Info Box

- Add exam details, course info, and instructions
- Text formatting: font size, alignment, bold
- Adjust height by dragging bottom-right corner
- Show/hide option
